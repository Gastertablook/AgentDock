# ADR-002：MCP 传输层用 Streamable HTTP，弃用手写 SSE

- 日期：2026-11-19
- 状态：已采纳

## 背景

lumina-framework 的 MCP Server 为手写 JSON-RPC + SSE 实现。2026 年 MCP 规范（spec v5，2026-07-28）已无状态化核心：SSE 传输被废弃，**Streamable HTTP 成为基线传输**，并强制 OAuth 2.1 鉴权。

## 决策

AgentDock 全部 MCP Server（rag-mcp / memory-mcp / sandbox-mcp）使用**官方 MCP Java SDK**（`io.modelcontextprotocol.sdk`）实现，传输层采用 Streamable HTTP，不再维护手写协议代码。

## 后果

**正面**：协议符合 2026 行业基线；与主流客户端（Claude Code/Claude Desktop/LangGraph 等）兼容；工具可发现性（`tools/list`）可被 MCP Inspector 协议级验证；本决策记录了协议演进（SSE → Streamable HTTP）的第一手经验。

**负面**：需要学习官方 SDK 的使用方式；弃用 lumina 手写实现（其价值保留为"啃过协议"的经验，而非代码资产）。
